CleanShot

An AI-powered photo studio for our used-equipment listings. One operator, four clicks, marketplace-ready images.

What it is, in one paragraph

CleanShot is an internal web app that takes the rough photos our sales team shoots on the lot — sometimes lit well, sometimes not, sometimes with a busy yard background — and turns them into clean, professional, marketplace-ready listing images. The operator uploads photos, the AI cleans them up, a second AI checks each result for problems, the operator picks the best version, the app crops them to the size each marketplace wants, and they're ready to publish. The whole pipeline happens in the browser. No Photoshop. No outsourcing. No per-seat license.

Who uses it

Internal employees only. The sales team that lists used forklifts, scissor lifts, and telehandlers on marketplaces. Authentication is Microsoft SSO (single sign-on) tied to our Microsoft 365 tenant, so the people who use it are the same people who already have company email. No external customer access — this is a tool for our operations team, not a product we sell.

The operator's day, in five clicks

1

Upload

Drag in photos straight from the phone or computer. Up to 10 per batch. The app auto-converts to JPEG and uploads to our cloud storage.

2

Enhance

AI cleans up each photo — fixes lighting, removes background clutter, preserves real wear and dents. The operator picks the best version out of up to six AI takes per photo.

3

Scan

A second AI inspects each cleaned photo for problems — missing parts, wrong colors, weird artifacts — and either approves it or flags it for a re-do.

4

Modify optional

Darkroom-style brightness / contrast / saturation / crop / straighten. Instant, no AI. Skip if the AI got it right; tweak per-photo if it didn't.

5

Resize & Publish

One click crops to the size marketplaces want, optionally stamps an "AI-enhanced" disclaimer, and composes a branded multi-image collage. Download or save to library.

What we pay for (and what we don't)

What's free

No per-seat license. No subscription tier per employee. No external customer billing — the tool isn't sold; it's used internally. Adding another employee costs us $0 in software.

What's metered

AI vendor costs are per-image. Each photo that runs through Enhance costs us roughly a few cents in AI compute (Gemini, OpenAI, Grok, Flux-Kontext, Ideogram, or Reve, depending on which model is used). Scanning is similarly per-image. Resizing, exporting, and the Modify (darkroom) tab cost effectively nothing — those are local image operations on our own server. All vendor spend is tracked per-user in the admin dashboard so we can see exactly where the budget goes.

Roughly

A typical forklift listing (5 photos) runs through the full pipeline for under a dollar in vendor costs end-to-end. The savings vs. outsourcing the same work is the entire point.

What's working today

  • Microsoft SSO login — same credentials as company email; no separate password to manage.
  • AI Enhance with 6 model options — Gemini, OpenAI, Grok, Flux-Kontext, Ideogram, and Reve. The operator can pick any subset (or hit "Select all"); the system runs each chosen model in parallel and shows them side-by-side for the operator to pick the best.
  • AI Scan with 3-vendor consensus — Gemini, OpenAI, and Anthropic all review each photo independently. If two of three flag a problem, the system warns the operator before publishing.
  • Darkroom (Modify tab) — brightness, contrast, saturation, crop, and straighten controls between Scan and Resize. Non-AI; instant. Optional — an operator can skip straight to Resize, or use Modify standalone on raw uploads without running Enhance first.
  • Per-variant fix tools — if one corner of one photo is wrong, the operator can paint over it (Erase / Inpaint) or type a sentence (Tweak / Edit) to fix just that part without redoing the whole photo. Four backend tools: Gemini, Flux, and two Ideogram tools tuned for repairing brand decals and model numbers.
  • Branded collage — composes our standard 1-hero-plus-4-thumbs marketing layout in one click. Operator picks equipment type (forklift, scissor lift, telehandler) and downloads a marketplace-ready collage. Matches the existing company template.
  • AI-disclaimer watermark — optional checkbox burns a tiny, semi-transparent line into the bottom-right corner of every exported image so customers know it's an AI-cleaned representation.
  • Admin dashboard — usage stats per employee, support ticket inbox, photo library with searchable downloads.
  • Photo library — every approved photo set is archived under the operator's account and kept indefinitely. Re-download any past listing's photos at any time.

What's coming next

  • Per-AI-model prompt tuning. Each AI model is best at slightly different things. Tailoring the instructions per model is the single biggest quality lever left.
  • Faster batch dispatch. A queue setting tweak (1 command) will let large intake days push through ~10× faster end-to-end.
  • Deeper usage analytics. Per-user cost breakdowns and quality trend dashboards in the admin tab.

If something breaks

Every page in the app has a built-in Support form. Any ticket submitted goes straight to the admin inbox; the operator who filed it gets an email reply when it's resolved.

For deeper issues (auth fails, uploads stuck, vendor outage), the engineering team monitors Cloud Run logs and gets paged on errors. There's a separate engineering README for the technical details.
