# Prompt Templates — How To

A template is a saved prompt that **everyone** on the team can use. One shared
library, not personal folders.

---

## Use one

1. Open **Enhance** → the blue **Use a shared template…** button, next to
   *Insert recommended prompt*.
2. Sort the list by **Top rated** (most upvotes), **Most used** (most loaded),
   or **Newest**.
3. Click a template. Its text drops into the prompt box.

You get a **copy**. Edit it however you like — the shared template never
changes.

## Save one

1. Write or edit a prompt until it produces a good result.
2. Click **SAVE PROMPT TO SHARED TEMPLATES**.
3. Give it a title and save. Everyone can see it immediately, credited to you
   with today's date.

**Titles are permanent.** Pick one that describes the machine and the
situation — "Sitdown Hyster, heavy rust" — not the date or your name, which are
added automatically.

## Change one

You can't. There is no rename and no edit, on purpose: a template's upvotes and
use count are ratings of *that exact text*.

To make your own version:

1. Load the template.
2. Edit the prompt box.
3. Save it under a **new** title — e.g. "Sitdown Hyster v2".

The original stays exactly as it was.

## Shorten a long one

Some prompts worth saving run to several pages. Nothing gets cut off — long
prompts work — but shorter ones usually produce a better photo.

Two reasons. First, much of the length is already free: the safety guardrails
(the real make and model, every decal exactly as it is, no added beacons or
mirrors, no invented damage, never a white studio backdrop) are appended to
*every* job. Restating them makes a prompt longer, not stronger. Second, the
automatic quality check is handed your prompt as its list of expected changes —
the more sprawling that list, the more it lets through.

1. With the long prompt in the box, click **Optimize prompt**.
2. Read the result. It shows the rewrite, what it **Removed**, and what it
   **Kept**.
3. Choose **Save as a new template** or **Use it in the box**. Nothing changes
   until you do.

**Read the Kept list.** Those are the five things CleanShot does *not* add for
you: tyre tread-vs-sidewall, camera angle and lighting and background, the
cheap-respray honesty line, what the paint doesn't cover, and paint-job quality.
They only work because they're in your words. If one is missing, don't save the
short version — every photo made from it would quietly get worse and still look
fine on screen.

**Save as a new template** leaves the long prompt in the box and files the short
one under its own title. You keep both. Title it so — "Sitdown Hyster, heavy
rust (short)" — because titles still can't be renamed.

## Rate one

Click **▲** on any template. One vote per person, and clicking again takes it
back. Votes drive the **Top rated** sort.

> **Top rated ≠ Most used.** Top rated counts how many people *endorse* a
> template. Most used counts how often it's been *loaded*. Something can be used
> constantly and rated by nobody.

## Delete one

Only an admin can. Deleting removes a template for everybody, so it isn't
something an author does to their own entry. Ask an admin if something needs to
go.

---

## Quick answers

| Question | Answer |
|---|---|
| Can I keep a template private? | No. Every template is visible to everyone. |
| Someone took the title I wanted. | Titles are one shared list and permanent. Pick another — adding "v2" keeps them side by side. |
| I edited the box after loading a template. Did I break it? | No. You edited a copy. |
| My template has a typo in the title. | It can't be fixed. Save a corrected one and ask an admin to remove the old. |
| Why is my template not at the top? | Default sort is Top rated. A new template has no votes yet. |

---

## For the team

The library is only as good as what goes in it. If a prompt gave you a result
you'd be happy to publish, save it — the next person shouldn't have to rediscover
it. And upvote what actually worked for you, not what sounds thorough; the votes
are how everyone else finds the good ones.
